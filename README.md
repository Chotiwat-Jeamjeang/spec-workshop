# TeamBoard — ระบบแจ้งจุดขยะภายในมหาวิทยาลัย

ระบบสำหรับแจ้งจุดที่มีขยะหรือถังขยะเต็มภายในมหาวิทยาลัย ให้เจ้าหน้าที่รับแจ้งและเข้าดำเนินการได้อย่างรวดเร็ว โดยมี AI ช่วยจำแนกประเภทขยะและวิเคราะห์ระดับความเร่งด่วนในการจัดเก็บจากรูปภาพที่ผู้ใช้งานแนบมา

## คุณสมบัติหลัก

- แจ้งจุดขยะผ่านการสแกน QR Code ที่ติดอยู่กับจุด/ถังขยะ หรือเลือกจุดจากรายการในฟอร์มโดยตรง
- แนบรูปภาพขยะได้สูงสุด 3 รูปต่อรายการ (jpg/png/webp, ไม่เกิน 5MB ต่อไฟล์)
- AI จำแนกประเภทขยะ: ขยะทั่วไป, ขยะรีไซเคิล, ขยะอินทรีย์, ขยะอันตราย
- AI ประเมินระดับความเร่งด่วนในการจัดเก็บจากสัดส่วนพื้นที่ขยะปกคลุมในภาพ (🔴 เร่งด่วน / 🟠 ควรดำเนินการ / 🟢 ไม่เร่งด่วน)
- แจ้งเตือนเจ้าหน้าที่ผ่าน LINE Messaging API ทันทีที่มีรายการใหม่
- เจ้าหน้าที่ติดตามและอัปเดตสถานะรายการได้ (รอดำเนินการ → กำลังดำเนินการ → ดำเนินการเสร็จสิ้น)

รายละเอียดข้อกำหนดทั้งหมดอยู่ใน [`SPEC.md`](./SPEC.md)

## Tech Stack

- Node.js + Express
- HTML / CSS / JavaScript
- JSON สำหรับจัดเก็บข้อมูล (`waste-reports.json`)
- QR Code
- AI สำหรับจำแนกประเภทขยะและวิเคราะห์ระดับความเร่งด่วนจากภาพ
- LINE Messaging API สำหรับแจ้งเตือนเจ้าหน้าที่

## Security & AI Ethics

- จำกัดชนิดและขนาดไฟล์รูปภาพที่อัปโหลดได้ ตรวจสอบ MIME type จริง
- ทำ face-blur อัตโนมัติหากภาพติดใบหน้าบุคคล ไม่เก็บข้อมูลส่วนบุคคลที่ไม่จำเป็น
- ผลวิเคราะห์จาก AI เป็นเพียงคำแนะนำ การตัดสินใจสุดท้ายเป็นหน้าที่ของเจ้าหน้าที่ ผู้ใช้งาน/เจ้าหน้าที่แก้ไขผลวิเคราะห์ได้
- ไม่เปิดเผยข้อมูลภายในระบบแก่บุคคลที่ไม่เกี่ยวข้อง
