Complete the two remaining entry paths on top of the tracer: the manual dropdown picker for someone who opens the form directly, and the rejection state for a QR whose `location_id` is not a registered point.

Purpose: after the tracer, a user could only arrive via a valid signed QR. This plan makes the form reachable and usable without any QR at all (SUBM-01's second path) and makes a bad QR fail clearly and recoverably (SUBM-02).
Output: `GET /report` handles all three states from one template and one registry read; `GET /api/locations` exposes the registry as JSON.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser → `GET /report` query string | Untrusted, unauthenticated; `location_id` and `sig` are attacker-controlled on every request. |
| browser → `GET /api/locations` | Unauthenticated public read of registry data; the projection decides what leaves the server. |
| `locationStore` → rendered `option` text | Registry `name` values flow into HTML; their provenance changes once an admin UI exists. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-04 | Information Disclosure | `GET /report` failure branch | medium | mitigate | One consolidated failure branch emitting one message string; enforced by a test asserting the four failure bodies are byte-equal, and by a source assertion that the message literal appears exactly once in the route. |
| T-01-10 | Information Disclosure | `GET /api/locations` response | medium | mitigate | Explicit projection to `{location_id, name}` — `lat`/`lng` never leave the server; asserted by a key-set test on every returned item. |
| T-01-03 | Tampering (script injection) | dropdown `option` text and the error message interpolation | high | mitigate | EJS escaping output tag on every interpolation in the dropdown and error branches; the unescaped tag is asserted absent from the template. |
