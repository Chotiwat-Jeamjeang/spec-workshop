  <action>
Create `public/css/report.css` as a hand-authored, mobile-first stylesheet. No preprocessor, no framework, no build step.

Start with a minimal base layer: `box-sizing: border-box` inherited from the root, zeroed body margin, and the font declaration adopted verbatim from the UI contract — `system-ui, -apple-system, "Segoe UI", "Leelawadee UI", "Noto Sans Thai", sans-serif`. Every major OS already ships a Thai-capable face, and CSS falls back per-script automatically. Declare no custom typeface and reference no remote stylesheet or asset from anywhere in this file; the whole point of the system stack here is that the page issues zero extra network requests before first paint, which is the largest single lever on the FCP target.

Define the spacing scale as custom properties on the root using exactly the declared token values: 4, 8, 16, 24, 32, 48 and 64 pixels. Use only these tokens for margin and padding. The one deliberate exception is the 44px minimum touch-target height, which is not on the 4-multiple scale and applies to `.location-select`, `.cta`, and `.location-not-this` at every breakpoint.

Define the palette as custom properties, exactly four roles and no more: page background `#FFFFFF`, secondary surface `#F1F5F9`, accent `#16A34A`, destructive `#DC2626`. The one supporting neutral is the `#CBD5E1` border used by the dropdown container. Apply accent to exactly three things and nothing else: the locked location block's left border and badge, the focus ring on every interactive element, and the primary CTA background. Apply destructive to error states only — the QR error banner, the note-length-exceeded message, and the validate-failure banner — and never decoratively.

Define the type scale as exactly three sizes and two weights: body 16px/400/1.5 for input values, note content, option text and banner message text; label 14px/400/1.4 for field labels, the note counter and microcopy; heading 20px/600/1.2 for the page title and the confirmed location name in locked state. CTA text reuses body size at heading weight; introduce no fourth size and no third weight.

Layout at the 375px default, with no media query: `.page` is single column and full width with 16px side padding, `.form-card` uses the secondary surface with 16px internal padding, fields stack with 16px between them, and the location block gets 24px above and below.

  <action>
Add the state treatments that make the two location states unmistakable at a glance while keeping them in the same DOM position with identical outer spacing (D-07). `.location-locked` gets the secondary surface, a 4px solid accent left border, and its badge and glyph in accent; `.location-locked__name` renders at heading size and weight — the weight bump is part of the distinction, not decoration. `.location-dropdown` gets the same secondary surface but a 1px solid `#CBD5E1` border and no badge and no accent border. `.location-not-this` styles as a text link in accent at label size, with the 44px minimum target height from Task 1.

Add `.is-hidden` as a `display: none` utility — this is what plan 01-05's toggle flips, so it must exist before that markup ships.

Add overflow behaviour. `.location-locked__name` wraps onto a second line rather than clipping: allow normal wrapping and word breaking, and set no `text-overflow` and no fixed height on it. Campus names are short today, but D-03 says the user replaces the placeholders with real data later and that must not need a code change. Apply no custom truncation to dropdown option text — native browser rendering owns it.

Add long-text behaviour for the note field: `.note-input` is a fixed height of roughly four to five rows, `resize: vertical`, with native internal scrolling for content beyond the visible area. Auto-growing is deliberately rejected: on a 375px screen a growing textarea shifts the CTA down while the user types.

Add the error and empty treatments: `.error-banner` uses the destructive colour for its border, glyph and text on the page background; `.error-banner__link` is a text link at body size; `.inline-error` is destructive at label size; `#validate-banner` (added by plan 01-06) shares the error-banner treatment; `.empty-state` uses muted body text with no destructive colour, because an empty registry is a configuration state rather than a failure.

Add a focus ring in accent to every interactive element — select, textarea, buttons and links — using a visible outline with offset. Do not remove the default outline without replacing it.

Add exactly two media queries, both `min-width`, in mobile-first order. At 768px: `.form-card` gets `max-width: 480px`, `margin-inline: auto`, and 24px internal padding. At 1024px: the same 480px centred card, with page vertical margin raised to 32px. No multi-column layout at any width — this is one short form and a second column adds complexity for no benefit. Add no third breakpoint and no `max-width` query.
